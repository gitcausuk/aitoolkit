# Review notes — 5 September 2026

The changes are limited to `index.html`, `assessment-designer/index.html` and
`assessment-designer/assets/app.js`, plus these explanatory files. Original
branding assets, all CSS files, accessibility/privacy pages, PDF guides, accessible
TXT alternatives, icons, format data and the Designer’s keyboard/focus-navigation
routines are preserved. Main-page changes are content/source strings, not a UI redesign.

## Substantive improvements

The web playbook and advice were brought closer to the caution already present
in the downloadable guides. Process evidence, distinctive writing, an early draft
or a viva is not a conclusive authorship test. AI permissions should follow the
specific task and applicable authority; a new viva, a marked declaration or a
change in criteria is not automatically a module lead’s unilateral decision.
Collections and vacation work are not automatically summative.

The Designer now carries uploaded source text and local requirements into its
working draft; prevents stale example inputs; preserves explicit evidence choices;
prioritises the declared department over incidental course keywords; and keeps
required AI use an explicit educator choice. Constraint-aware options and clearly
illustrative weights reduce misleading defaults. Copy failures are reported honestly.

The core script no longer waits for optional PDF/DOCX libraries. The built-in
rules work without an AI-model connection; file readers and external services
have separate availability and data-handling requirements.
