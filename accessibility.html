Accessibility statement

We want the Oxford Saïd AI Toolkit to be usable by as many people as possible.

What you should be able to do

You should be able to zoom the site, navigate it with a keyboard, use a screen reader and understand links without relying on surrounding text. The layouts adapt to smaller screens and respect reduced-motion settings.

Review status

We aim to meet WCAG 2.2 AA. Full conformance has not been established. Keyboard operation, responsive layouts and core workflows have been checked; this is not a complete assistive-technology or PDF accessibility audit.

Known limitations and remaining checks

  • The interactive toolkit and Assessment Designer require JavaScript.
  • The three assessment resource PDFs have not completed a formal accessibility audit. Tagging alone does not establish correct reading order or accessible tables. Matching plain-text versions are provided below. Centre for Teaching and Learning (CTL) briefing notes are not hosted on this site; the Toolkit links to CTL's own guidance instead.
  • Some third-party University documents linked from this site may have their own accessibility limitations.

Text alternatives to the PDFs

  • 40 assessment formats: plain text
  • Assessment design checklists: plain text
  • VIVA reference: plain text

Using the Assessment Designer

Form fields have visible labels, required fields are identified in text and validation messages are announced. Uploaded files are processed in your browser. If a PDF or Word file cannot be read, paste the relevant text into the labelled field.

Report an accessibility problem

If you need information in another format or find an accessibility problem, email David Dodick about Oxford Saïd AI Toolkit accessibility. Include the page or feature involved and the format you need.

Further work

Remaining checks include screen-reader announcements, PDF reading order and table navigation, and speech-input use. No completion date has been set for a full audit. Report a barrier using the contact above so it can be investigated and an alternative provided. The hosting unit should confirm the applicable accessibility reporting and escalation arrangements before publication.

See the University accessibility information for Oxford's wider approach and reporting information.

This toolkit is independently maintained practical guidance. It is not an official University policy website.
