Privacy, cookies and website status

These notes describe how the static Oxford AI Toolkit package itself handles information. The privacy and logging arrangements of the final hosting service must be confirmed by the service owner before publication.

Privacy

The Toolkit does not contain analytics, advertising, tracking pixels, server-side forms or a database. It does not send entries from its decision tools, generators or AI Designer to the Toolkit maintainer.

The AI Designer processes pasted text and selected documents in the user’s browser using locally hosted document-reading libraries. Files are not uploaded by this application. Users should nevertheless avoid entering identifiable student work, unreleased examination material, confidential research, special-category personal data or other restricted information.

Some features create a local download or copy text to the clipboard. The user controls any subsequent use or sharing of that material. A link to the optional AI Adviser opens a separate ChatGPT service; users should review the prompt, use the Oxford-approved sign-in route where applicable, and follow University information-handling requirements.

Cookies and local storage

The delivered Toolkit code does not set cookies and does not store user entries in browser local storage or session storage. The eventual hosting platform may use essential security, authentication or server-log mechanisms outside this package. If analytics, authentication, embedded media or other cookie-setting services are added, this notice and any consent mechanism must be updated before deployment.

Server logs

A web host commonly records technical request information, such as an IP address, browser type, requested page and time of access, for security and operational purposes. The team responsible for the production hosting environment must document the applicable retention, access and privacy arrangements.

External links and services

The Toolkit links to University policy pages, guidance, support services and third-party platforms. When a user follows an external link, that destination’s privacy, cookie and accessibility terms apply. External links are opened safely with appropriate relationship attributes where a new tab is used.

Status and authority

This is a practical, independently maintained Toolkit. It is not an official University policy website and does not replace University policy, Examination Regulations, local requirements, reasonable-adjustment duties or approval processes. When a Toolkit statement conflicts with an authoritative source, the authoritative source governs.
